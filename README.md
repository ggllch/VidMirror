Сделал своё собственное расширение, так как популярный "VideoMirror" либо не работает с VK, либо работает с перебоями. А записи стримов посмотреть хочется.
Данная версия сделана для Google Chrome, но работает на Microsoft Edge и, скорее всего, в других браузерах.


Установка:
1. Скачать папку с расширением:
  - [Скачать Chrome ZIP](./downloads/VidMirror-chrome.zip)
  - [Скачать Firefox ZIP](./downloads/VidMirror-firefox.zip)
  - [Скачать Opera ZIP](./downloads/VidMirror-opera.zip)

2. Перейти и выбрать:
 - **Chrome:** `chrome://extensions` -> включить режим разработчика -> `Load unpacked` -> выбрать `browsers/chrome`
 - **Firefox:** `about:debugging#/runtime/this-firefox` -> `Load Temporary Add-on` -> выбрать `browsers/firefox/manifest.json`
 - **Opera:** `opera://extensions` -> включить режим разработчика -> `Load unpacked` -> выбрать `browsers/opera`
3. Включить режим разработчика
4. Нажать "Загрузить распакованное расширение" и выбрать папку с расширением
5. Должно заработать
