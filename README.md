Сделал своё собственное расширение, так как популярный "VideoMirror" либо не работает с VK, либо работает с перебоями. А записи стримов посмотреть хочется.
Данная версия сделана для Google Chrome, но работает на Microsoft Edge и, скорее всего, в других браузерах.

Установка:
1. Скачать папку с расширением
2. Перейти либо по chrome://extensions/ в поисковике, либо через меню - расширения
3. Включить режим разработчика
4. Нажать "Загрузить распакованное расширение" и выбрать папку с расширением
5. Должно заработать
